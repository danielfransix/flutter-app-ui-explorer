# Flutter App UI Explorer

Planning repository for a Flutter equivalent of [Web App UI Explorer](https://github.com/danielfransix/web-app-ui-explorer):
automatically discover every screen and state of a Flutter app, capture screenshots, and browse them as a gallery and flow canvas.

**Status:** planning only. No code yet.

- [PLAN.md](PLAN.md): goal, research on existing tools, approaches, architecture, phases, risks and open questions.
